# 改进路线图

截至 2026-09-19，当前版本为 0.5.0。实现、验证与远程发布分别记录，不把本地通过当成云端端到端证明。

## 已实现

- 本地提示词/目录管理、JSON/CSV 原子导入预览、安全导出、版本冲突保护和跨页面通知。
- 卡片/精简展示、13 种主题、单击使用、变量填写、目录排序、侧栏稳定排序及快捷键。
- 用户自建 Supabase schema v3，URL + publishable/anon key，无 Auth 登录。
- 页面先使用本地数据，再单次增量拉取；完整管理页手动上传，无轮询、定时任务或后台监控。
- 冻结请求与幂等确认、冲突选择和恢复备份、删除传播及项目切换保护。

当前用法见 [云同步指南](cloud-sync.md)，本地验证见 [0.5.0 记录](reviews/2026-09-19-v0.5.0-sync.md)。早期版本证据保留在各自的验证记录，不改写历史结果。

## 待验证与交付边界

- 用户目标 Supabase 的真实 key、HTTP 网关、原生域名授权与两台设备联调。
- 大数据量同步的耗时、内存和弱网测量；现有本地列表基准不证明同步性能。
- 本轮远程 CI 完成状态；现有 GitHub Actions 不执行独立 PostgreSQL 测试。
- 正式许可、权属与安全接收渠道仍由维护者确认。

## 后续候选

根据实际需求评估网页插入、嵌套目录界面、自托管域名与更大关联事务。保持最小权限和本地优先；云端日志回收、云端全清及旧设备恢复需要配套协议，不能直接删日志或墓碑。

周期同步与实时订阅不在当前需求范围内。
