# 改进路线图

截至 2026-09-18，0.2.0 已落地数据可靠性及展示改造代码。实施完成不等于所有运行环境已验证，逐项证明见 [实施清单](implementation-checklist.md) 与后续验证记录。

## 本轮实现

严格 JSON/CSV 校验、覆盖预览及过期基线检查、原子导入、事务内版本保护、设备身份迁移、跨页面通知、模板单次替换、CSV 安全/原始导出、失败反馈、DB 连接生命周期、一致快照和有界队列。

新增精简卡片与 13 个主题选项，提取共享变量/弹窗模块，改进最近使用排序、侧栏截断提示、增量渲染。增加静态检查、单元/模拟 DB 测试、真实扩展测试、性能脚本、CI 配置及白名单打包。

## 发布前收尾

- 完成并记录真实扩展、并发/备份、可访问性与 100/1,000/10,000 条合成数据验证。
- 维护者确认权属、许可证、正式安全渠道与支持范围。
- 检查最终发布包；获得对应授权后初始化 Git，再检查提交集合和历史。
- 远程 CI 实际运行后记录结果；本地通过不能替代远程证据。

## 后续能力

根据真实需求选择网页插入、嵌套分组、拖拽等能力，评估权限和兼容成本。云同步另行设计身份隔离、幂等重试、游标、墓碑传播、冲突副本和全量重扫，再选择服务提供方。界面仍优先本地读写。

本轮执行结果与剩余边界见 [0.2.0 验证记录](reviews/2026-09-18-v0.2.0-validation.md)。
