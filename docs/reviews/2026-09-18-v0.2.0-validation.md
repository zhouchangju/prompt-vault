# 0.2.0 实施与验证记录

日期：2026-09-18。对应 [原始审查](2026-09-18-readiness.md) 与 [ADR 0002](../decisions/0002-compact-themes-hardening.md)。

## 结果

原始审查 A01–A12 的代码问题、精简模式和主题功能均已实现，并完成下述本地验证。维护者的许可证、公开安全渠道及正式发布决策仍未完成；没有初始化 Git、推送、发布或宣称远程 CI 通过。

精简模式是真正的标题卡片，不创建正文、描述、标签和使用记录节点；保留复制、编辑、删除，全文仍参与搜索。12 个命名主题加跟随系统，管理页与侧边栏实时同步设置，兼容旧偏好。

数据改造保持原库名称与版本，加入事务内版本校验、过期导入预览保护、一次性模板替换、严格 CSV、原子导入及跨页变更通知。队列按实体压缩并限量。模块、测试、白名单打包与 CI 配置已落地，图标替换为项目脚本生成的几何标识。

## 验收覆盖

- **A01–A03：** schema/类型/重复 ID/引用校验，损坏 JSON/CSV 零写入，真实 IndexedDB 写入中途配额异常整体回滚，过期预览拒绝；实体保存和删除版本检查，旧版迁移及清空恢复后的旧编辑拒绝。
- **A04–A07：** 双页面变更传播且保留草稿；模板值中的 token 保留字面内容；默认 CSV 保护公式前缀；剪贴板、文件读取、配额失败显示错误并保留输入。
- **A08–A09：** 真实 versionchange 关闭旧连接，首次打开失败后恢复；原始 v1 数据与设备标识迁移；统一快照、队列合并和 10,000 条上限回归。onblocked 提示代码存在，当前 schema 无需版本升级，未构造真实升级阻塞场景。
- **A10–A12：** 加载更多保留既有卡片节点、正文预览限制长度、侧栏显示总数并继续加载；最近使用默认排序；共享变量表单、背景 inert、弹窗焦点、嵌套草稿及关闭恢复。
- **F01/F02：** 两种视图切换与重开持久化、隐藏正文仍搜索、真实剪贴板、13 主题跨页面更新；全主题两种视图及侧栏自动可访问性检查，另验证系统深色响应。
- 补充实际浏览器断言通过：1440/1000/600 像素下精简视图分别为三/二/单列且无横向溢出；侧栏复制后使用排序即时更新，管理页最近使用筛选默认按使用时间排序。

## 复审期间修复的额外问题

清空/恢复的版本重用、深层文件夹校验二次复杂度、外来极端版本号污染时钟、预览引用原始 tags 数组、快速重复提交、嵌套文件夹操作覆盖其他草稿、错误的弹窗标题关联和焦点逃逸均已回归覆盖。

一次失败的浏览器 trace 还揭示延迟聚焦会把刚输入的正文送入标题。改为同步初始聚焦后，跨页/变量/嵌套弹窗用例重复三轮，9/9 通过；之后完整 13 项套件通过。旧设置迁移测试发现后台默认值写入竞争，现已取消后台写默认偏好，改为读取时提供默认值。

## 性能

1440×1000、每条正文约 735 字符，3 次页面重载与 5 次搜索。目标在执行前设为：显示完成 <3 秒、搜索含防抖 <1 秒、首次追加 <2 秒。

| 提示词数 | 页面重载显示中位数 / 最大值 | 搜索中位数 / 最大值 | 首次增量追加 |
| ---: | ---: | ---: | ---: |
| 100 | 164 / 398 ms | 99 / 115 ms | 62 ms |
| 1,000 | 297 / 346 ms | 98 / 99 ms | 102 ms |
| 10,000 | 164 / 229 ms | 102 / 116 ms | 67 ms |

这是同一 Chromium 进程中的页面重载，包含缓存影响，不是冷启动或所有设备的性能承诺。搜索含 80ms 防抖与两帧显示等待；追加含自动化驱动耗时，测到 100/120 个卡片，不是滚动渲染全部一万条。样本少，不能据此断言一万条比一千条快。

## 剩余边界

自动化在实际 extension origin 运行，侧栏页面以扩展页打开；未点击浏览器原生工具栏或以真实停靠面板验证，也未覆盖操作系统快捷键、屏幕阅读器、Chrome 116 本体、其他操作系统或商店发布。

缺少 Git 的初始目录不能产生历史/远程 CI 证据。维护者仍需选择许可证、确认发布权属及正式私密报告渠道。云同步、网页注入、嵌套文件夹 UI 和拖拽是后续产品范围，没有伪装为本轮已实现功能。
