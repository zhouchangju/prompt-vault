# 0.3.0 交互优化验证

日期：2026-09-18。方案见 [ADR 0003](../decisions/0003-one-click-interactions.md)，操作说明见 [快捷键与使用指南](../interaction-guide.md)。

## 实现

- 完整、精简、侧栏三类卡片默认点击使用；有变量先填写，无变量直接复制。编辑、删除、收藏不串操作，选中文字不复制。
- 侧栏左列全部/收藏/未分类/文件夹与数量，保持搜索条件，一次点击切换；320/360/420px 布局检查无横向溢出。
- 卡片星标直接切换收藏并同步其他页面；按实体保留节点，重绘与排序变化恢复焦点。
- 打开完整管理页使用 Chrome 的 options 入口复用已有页面，成功后关闭来源侧栏；新建也收起侧栏，打开失败保留面板。
- 浏览器快捷键、搜索、方向键选卡片、Enter/Space 使用、表单提交、Esc 与可见帮助入口。
- 38px 操作目标、搜索清除、重复提交保护、IME Esc 防误关；区分剪贴板失败和复制后的记录失败。

## 验证

环境：Node.js 22.19.0、Playwright 1.63.0、Chromium 153.0.8010.12，macOS arm64。仅使用独立临时浏览器 profile 和合成数据。

| 项目 | 结果 |
| --- | --- |
| npm run verify | PASS：静态检查、50 个 Node 测试、19 个 Chromium 扩展测试 |
| 新交互浏览器用例 | 6/6，通过三类卡片、独立操作、分类/星标、键盘/IME、部分失败、原生侧栏关闭 |
| 既有回归 | 13/13，包括所有主题的卡片/精简/侧栏 axe 检查、旧数据迁移、导入事务与并发 |
| 独立代码复审 | 已修复 IME Esc、Option+N 字符布局问题、复制后记账错误提示；复审无待修问题 |
| 固定目录 build 验收 | PASS：dist/prompt-vault/ 生成 25 个白名单文件，整卡/侧栏导航/原生关闭三项成品测试通过 |
| ZIP 分发回归 | PASS：npm run test:package，解压后的 6 项成品测试全部通过 |

原生侧栏测试从真实点击事件调用 Chrome 打开面板，确认 SIDE_PANEL 上下文出现。由于该原生页面不在 Playwright 的页面列表中，仅对独立测试浏览器使用 CDP 调用面板内实际箭头事件处理；随后观察到 Chrome onClosed 事件以及 SIDE_PANEL 上下文移除。没有 mock 此关闭路径，也没有对用户浏览器执行操作。

浏览器级快捷键已检查 manifest 注册；实际操作系统按键冲突和 Chrome 116–140 的关闭回退仍未实机验证。故障分支使用专门注入或 API 契约测试，不将其视为原生成功证据。

## 更新
