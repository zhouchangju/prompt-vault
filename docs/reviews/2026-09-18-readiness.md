# Prompt Vault 代码与开源准备审查

日期：2026-09-18。对象：解压后的 0.1.0 源码及本次补充的文档。

## 结论

- 主要建议：**整理后开源**。当前为 MVP 整理阶段，不宜作为稳定版本发布。
- 当前是否可切 Public：**证据不足**。目录无 `.git`、remote、历史；许可证、图标来源、Chrome 运行验收未完成。
- 开源价值 **31.5/55**，发布准备度 **21.6/45**，总分 **53.1/100**，置信度 **低**。
- 主要问题是数据可靠性与验证缺口。目录扁平、没有 React/TypeScript 本身不是质量缺陷。

评分是主观优先级判断，不是安全认证或社区采用预测。目标用户假设为希望本地管理提示词的 Chrome 用户；维护预算和长期支持承诺待定。

## 已核实优点

原生模块无需安装依赖或构建；manifest 只请求 storage、sidePanel、clipboardWrite。正文通过 `textContent` 展示，未发现执行正文或拼接正文为 HTML 的路径。普通保存将实体和队列放入同一写事务，删除文件夹保留提示词。主要功能均有对应代码。

## 发现与优先级

P1 建议正式发布前解决；P2 是后续体验与工程改进。以下均未在本次文档整理中修复。

| 级别 | 位置 | 问题与影响 | 验收要求 |
| --- | --- | --- | --- |
| P1 | `db.js: importSnapshot` | 只检查顶层数组，忽略 schema、类型、重复 ID、分组引用，同 ID 无条件覆盖 | 全量预校验、覆盖预览、回滚及往返测试 |
| P1 | `db.js: importSnapshot`；`manager.js: importCsvRows` | JSON 遍历中同步异常无显式 abort，已有请求可能提交；CSV 每行事务会部分落库 | 真实 IndexedDB 中途坏行测试，明确全量回滚或部分导入协议 |
| P1 | `db.js: savePrompt/saveFolder/getDeviceId` | 读旧记录与写入分离，无版本检查；设备 ID 初始化有竞争窗口 | 双页并发不丢更新，设备标识初始化稳定 |
| P1 | `sidepanel.js: init/bind`；`manager.js: reloadData` | 没有页面间变更通知，侧边栏长驻读旧值，复制后也不更新内存使用时间 | 广播/恢复刷新、排序与删除可见性测试 |
| P1 | `shared.js: resolveTemplate` | 后一个变量再次替换前一个填写值内的 token | 只替换原始模板，用户输入保留字面内容 |
| P1 | `shared.js: parseCsv/snapshotToCsv` | 接受未闭合引号，导出保留公式前缀，电子表格存在解释风险 | 异常格式测试，安全导出与无损文本策略 |
| P1 | 两个页面异步事件 | 多数保存/复制无错误捕获，`file.text()` 在导入 try 外 | DB/剪贴板/文件失败可见且表单可恢复 |
| P2 | `db.js: openDatabase` | 无 blocked/versionchange 处理，缓存首次失败 Promise | 升级占用提示、关闭旧连接和失败重试 |
| P2 | `db.js: exportSnapshot/syncQueue` | 导出为两个独立读事务；队列无消费者、确认或压缩 | 一致快照、队列生命周期，再设计同步 |
| P2 | `manager.js: renderCards` | 加载更多重建全部展示卡片，视觉截断不减少文本 | 合成数据测量后选增量渲染或虚拟列表 |
| P2 | `manager.js: getFilteredPrompts`；`sidepanel.js: render` | 最近使用筛选沿用原排序，侧栏截断 120 条无提示 | 明确默认排序与结果截断提示 |
| P2 | 两个 `createVariableField` 及弹窗 | 重复实现、焦点管理不足、侧栏弹窗语义不完整 | 共享字段、键盘和辅助技术验收 |

并发覆盖和导入异常部分提交属于源码推导风险，尚未在 Chrome/IndexedDB 复现，不是已经完成的漏洞验证。

## 执行证据

环境：Node.js 22.19.0。

| 检查 | 结果 | 边界 |
| --- | --- | --- |
| 五个 JS 的模块语法 | PASS | 不执行 Chrome API |
| manifest/HTML 资源 | PASS | 路径存在不等于扩展可运行 |
| 标签、变量类型/默认值、CSV 引号与换行往返 | PASS | 临时探针，尚无持久化测试套件 |
| 模板 `{{a}} / {{b}}`，填写 a 为 `{{b}}`、b 为 VALUE | 缺陷复现 | 实际 VALUE / VALUE；字面保留目标是 `{{b}} / VALUE` |
| CSV 表头 title,content，数据行 `hello,"unterminated` | 缺陷复现 | 未闭合引号仍解析成一行 |
| CSV 标题 `=1+1` | 风险条件复现 | 导出保留公式前缀，未在电子表格执行 |
| 初始 12 个文本文件凭据模式初筛 | 无中高等级凭据线索 | 不证明来源清白，不覆盖图像、系统文件或历史 |
| 标准开源扫描器 | FAIL，退出码 2 | 原因 Not a Git repository；未为扫描擅自初始化 Git |
| Chrome、IndexedDB、多窗口、可访问性、性能 | UNVERIFIED | 本次未执行 |

## 对抗式复核

最强反例：文档齐全后看起来成熟，实际扩展可能仍有安装或数据故障。因此文档得分不能替代运行证据，也不建议用复杂框架制造成熟感。

尚无证据证明本项目比其他工具更快、更有差异或值得长期运营。当前方向适合小型实用工具，不据此预测社区影响力。

改变结论的最小证据：Chrome 核心流程、导入失败及并发回归通过，许可与来源明确，最终发布包和 Git 历史审查完成。
