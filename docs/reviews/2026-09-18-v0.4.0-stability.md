- 工具栏与页面品牌图标改为原创大写 P 与青绿提示光标，包含 16/32/48/128px。

- Mac 建议 Command+Shift+Y 打开侧栏、Command+Shift+P 打开管理页；帮助页显示实际绑定及未分配状态。

## 快捷键排查边界

原实现的帮助文案展示建议值，未读取实际分配。新实现通过 chrome.commands.getAll 获取当前按键，空值明确标为未分配，并提供用户主动打开配置页和重新检测入口。侧栏改为明确的 open-panel 命令，直接使用命令事件提供的窗口 ID 调用原生 API，不新增权限。

电脑操作工具拒绝访问 Chrome 内部快捷键页面，该 Computer Use 会话已停止；没有通过其他工具读取或修改用户 profile 来绕过限制。因此没有证据把用户现场失效唯一归因为权限、冲突或未重新加载。

独立 Chromium 中的绑定元数据与命令处理函数已验证，命令处理路径能打开原生 SIDE_PANEL。自动化派发的键盘事件不等于操作系统向 Chrome 分发的物理快捷键；用户原浏览器上的实际按键触发仍需现场确认。没有声称完成该证明。

[Chrome 官方 Commands 文档](https://developer.chrome.com/docs/extensions/reference/api/commands) 说明快捷键冲突可能导致未注册，getAll 的空 shortcut 表示没有激活；不是只写 suggested_key 就能保证绑定成功。

## 数据与更新

数据库名称和版本不变，使用次数持续累加，不因本轮升级清零。保持原来的 dist/prompt-vault 安装路径，更新文件后在 Chrome 点击重新加载，不需要卸载扩展或重新导入提示词。远程 CI、Git 提交和公开发布不在本轮执行范围。
