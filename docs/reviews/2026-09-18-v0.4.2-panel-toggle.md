# 0.4.2 侧栏快捷键开关

快捷键与命令 ID 保持不变：Mac 的 Command+Shift+P、其他平台的 Ctrl+Shift+Y。当前窗口未打开则打开，已打开则关闭。

## 实现

`core/panel-toggle.js` 使用原生 onOpened/onClosed 事件跟踪可见状态，覆盖工具栏打开、外部关闭和快捷键操作；状态按窗口隔离，保存在 chrome.storage.session。后台休眠后可恢复判断，不把 sidePanel 配置中的 enabled 当作实际可见状态。

同一窗口尚未完成的操作合并，避免重叠请求。API 先完成而事件延迟时补写成功状态；若期间已出现新的原生事件，则以该事件为准，不覆盖用户手动操作。窗口状态按顺序持久化，写入记录失败不将实际开关成功误报为失败。

原生 onClosed 从 Chrome 142 起提供，因此最低版本更新为 142。本机安装的 Chrome 153 满足要求。[官方 Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)

## 验证

完整 `npm run verify` 通过：70 项 Node 测试、28 项 Chromium 扩展测试，静态检查通过。

- 单元覆盖连续打开/关闭/重开、外部事件、多窗口隔离、后台恢复、失败重试、重叠按键和延迟事件。
- 独立 Chromium 中验证原生 opened/closed 事件和 SIDE_PANEL 上下文：打开 → 关闭 → 重开；再通过外部原生关闭调用模拟手动关闭，下一次快捷操作正常打开。
- npm run build 生成 29 个白名单文件；同一原生开关用例在固定安装目录上再次通过。
- 独立代码审查发现并修复了事件晚于 API Promise 时的重复打开窗口，复审通过。

使用合成测试环境，未改变用户的日常浏览器配置或提示词数据。
