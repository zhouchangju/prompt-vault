# 产品范围

0.4.0 面向需要本地整理、搜索和重复使用提示词的 Chrome 用户。日常操作不依赖网络；离线可用不代表任何数据量都已达到性能目标。

管理页支持提示词与单层分组 CRUD、标签、收藏、最近使用、搜索及卡片/精简两种展示。精简卡片隐藏正文、描述等信息，仍可搜索全文和执行复制、编辑、删除。展示模式与舒适/紧凑密度独立。

主题提供跟随系统和 12 个命名配色，无付费限制；管理页与侧栏共用主题，设置持久化并跨页更新。变量提示词先填写后复制，普通提示词直接复制，成功后记录使用时间与次数。

JSON/CSV 导入先预览，再原子提交；并发变化会阻止过期覆盖。JSON 是推荐手动迁移格式，CSV 不保留实体身份及完整元数据。删除没有撤销界面。

所有卡片可点击非操作按钮区域直接使用；侧栏左列展示分类并可原地切换收藏。打开管理页后自动收起来源侧栏。搜索、卡片和表单都有键盘入口，详见 [交互指南](interaction-guide.md)。

尚未实现云同步、账号、网页插入、嵌套目录 UI、提示词拖动分组和全文索引。最初讨论中的框架与服务商只是候选方案；本轮保持原生实现。后续同步需独立设计认证、冲突副本、幂等重试、删除传播与设备生命周期。

需求与验收见 [ADR 0002](decisions/0002-compact-themes-hardening.md)、[实施清单](implementation-checklist.md) 和 [验证指南](testing.md)。参考截图用于说明交互需求，不作为像素一致性承诺。

0.4.0 支持文件夹拖动排序、侧栏收藏/累计次数稳定排序、多行变量、顶部新建和单按钮展示切换，见 [ADR 0004](decisions/0004-stable-panel-and-mac-shortcuts.md)。
