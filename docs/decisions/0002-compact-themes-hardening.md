# ADR 0002：精简展示、主题与可靠性改造

日期：2026-09-18。状态：方案已实施；验收以本轮验证记录为准。

## 新增体验

精简模式参考用户提供的紧凑标题卡片：桌面三列，自适应两列/单列；隐藏描述、正文、标签和使用时间，保留标题及明确的复制、编辑、删除操作。正文仍参与搜索，含变量的提示词仍先填写再复制。与既有「舒适/紧凑」密度分离，新增 `viewMode: cards | compact`，管理页工具栏可直接切换并持久化；键盘可操作，切换不改变内容和筛选。

主题独立于展示模式：跟随系统、冬季、浅色、深色、夜间、赛博朋克、复古、情人节、水蓝、北欧、柠檬水、森林、奢华。名称来自需求截图，配色由项目自行定义，不复制外部样式包，不设置付费限制。管理页提供主题下拉入口和设置入口，侧边栏共用主题 token；打开的页面通过设置变更事件即时响应。未知旧值回退到系统主题，现有 light/dark/system 兼容。

## 数据与页面契约

- 数据库名称保持不变；旧数据兼容，保留根目录入口与无构建运行方式。
- 保存已有实体必须携带读取时的版本；事务内读、比较、写入，冲突保留编辑内容并提示重新读取，禁止静默覆盖或复活已删记录。
- JSON/CSV 全量验证后在单一事务提交。导入先预览新增/覆盖数量；确认时再校验预览基线，防止等待确认期间覆盖新修改。
- JSON 维持 schemaVersion 1 的存活实体迁移格式，明确不导出设置/墓碑。导出使用一个读事务。
- CSV 严格格式校验；默认电子表格安全输出会保护公式前缀，同时保留明确标注风险的原始文本导出选项；JSON 是推荐无损迁移格式。
- 队列只保留每实体的最新待同步意图，限制增长，不宣称云同步；使用记录保持本地但通知其他页面。
- 实体提交后广播失效通知；页面恢复焦点时再读取，保护未保存表单。剪贴板/存储/文件错误需可见。

## 工程实施

保留原生 ES modules，提取纯模板/CSV/搜索/主题定义及共享变量表单、弹窗、错误处理。增加 Node 测试、IndexedDB 测试、独立 Chromium 扩展回归、静态路径检查、白名单打包与 CI。

替换来源不明图标为本项目可复现生成的几何标识并记录来源。许可证与正式安全接收渠道需维护者决定；云服务、网页注入、嵌套目录属于后续产品能力，不在本轮可靠性修复范围。

## 验收

两种展示 × 全部主题可切换、持久化、跨页面同步；编辑/删除/变量/导入预览不回归。覆盖异常导入零写入、并发冲突、过期删除、广播恢复、失败提示、弹窗键盘操作和 100/1,000/10,000 条合成数据测量。报告区分静态、模拟 IndexedDB 与真实扩展结果。
