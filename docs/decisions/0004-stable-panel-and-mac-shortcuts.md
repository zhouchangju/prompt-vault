# ADR 0004：稳定排序与 Mac 快捷操作

日期：2026-09-18。状态：已实现，用户既有浏览器绑定仍待现场核对。

侧栏打开时，对每条提示词冻结本次会话的累计使用次数作为排序分数。收藏优先；同组按冻结次数降序，再按原有 sortOrder、创建时间和 ID 稳定排列。复制仍正常累计次数，但本次面板内不因使用或重新获得焦点而重排；下次打开面板再应用新的次数。主动收藏/取消收藏可以改变所属优先组。

文件夹使用持久化 sortOrder，两个界面均按同一规则展示；拖动由专门手柄发起，整批排序通过版本检查在单一事务保存。提供手柄 Alt+方向键的键盘替代。新建分组默认放末尾。

文字变量默认大号多行输入框；数字和选择变量保留原语义。侧栏新建按钮移到顶部帮助按钮左侧。管理页展示模式改为单按钮切换，文件夹图标使用可辨识的文件夹轮廓。

工具栏图标使用原创大写 P：深色圆角底、粗白字、青绿提示光标，16px 保持清晰。通过项目脚本生成，不引入字体/远程素材依赖。

快捷键分浏览器级命令与页面内操作。改用明确的 open-panel 命令处理侧栏打开，保留已有 open-manager；Mac 建议 Command+Shift+Y 与 Command+Shift+P。帮助页从 chrome.commands.getAll 读取实际绑定，未分配明确提示，并提供打开 Chrome 快捷键配置入口；不假设更新 manifest 会覆盖用户配置，不读取或改写 Chrome profile。

当前电脑操作工具拒绝访问 Chrome 内部快捷键页面，因此无法证明用户既有环境的具体冲突。通过源码、官方 Commands API 与独立 Chromium 测试验证；不将模拟按键或新 profile 结果当作用户现场验证。
