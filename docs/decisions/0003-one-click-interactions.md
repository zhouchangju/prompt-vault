# ADR 0003：一键使用与侧边栏导航

日期：2026-09-18。状态：已实现。

## 操作原则

- 完整卡片、精简卡片、侧边栏卡片的非操作按钮区域均为「使用」入口：无变量直接复制，有变量先填写；选中文字不触发复制。编辑、收藏、删除及其取消操作不能误触使用。
- 卡片可被 Tab 聚焦，Enter/Space 使用，方向键移动；卡片采用 group 语义，内部保持独立按钮，避免嵌套 button。复制/收藏目标至少 38px，清晰显示已收藏状态。
- 侧边栏固定左列展示全部、收藏、未分类和文件夹计数；窄面板也保持一次点击切换，不恢复下拉。列表独立滚动，长名称截断并提供完整标题。
- 右上箭头复用 Chrome 的完整管理页入口，成功打开后关闭来源窗口的侧边栏，不调用系统全屏。新建入口同样收起侧栏。Chrome 141+ 使用 sidePanel.close，旧版本保留 window.close 回退，失败不能阻止管理页打开。
- 重绘尽量保留正在操作的卡片/收藏按钮焦点；操作期间防止重复提交；搜索提供显式清除。

## 快捷键

浏览器级：保留 Command/Ctrl+Shift+P 打开管理页；新增 Alt+Shift+P 触发扩展工具栏动作（侧边栏开关），可在 chrome://extensions/shortcuts 修改。实际系统冲突由 Chrome 分配状态决定。

扩展页面内：Command/Ctrl+K 聚焦搜索；搜索框 ArrowDown 进入结果；卡片上下方向键移动，Enter/Space 使用；Alt+N 新建（不拦截输入）；弹窗 Command/Ctrl+Enter 保存/生成复制，Escape 关闭；无弹窗时 Escape 清搜索或返回搜索。输入法组合输入、按键长按及原生输入控件的编辑键不被抢占。两页都提供快捷键说明。

## 验收

覆盖卡片三种视图、变量流程、独立按钮不串操作、文本选择、星标同步及失败、分组一次点击、320/360px 布局、键盘与输入法、管理页打开失败保留侧栏。尽可能观察原生侧栏的打开/关闭事件；API mock 仅用于故障和兼容分支，不冒充原生界面证据。最后重新生成固定安装目录。
