# ADR 0001：本地优先、原生无构建 MVP

日期：2026-09-18。状态：记录当前实现与产品方向。

## 背景与决策

产品用于替代响应较慢的提示词管理扩展，要求提示词管理、分组、卡片展示，最终支持多电脑使用，初期接受本地存储。

- IndexedDB 是当前提示词和文件夹主存储；设置使用 `chrome.storage.local`。
- 日常读取、搜索和编辑不等待网络。
- 保持原生 JavaScript ES modules，无构建步骤，根目录直接加载为扩展。
- 未来云能力以异步同步模块引入，供应商未定。

## 备选与取舍

早期讨论中的 WXT + TypeScript + Preact/React + Dexie 尚未采用。原生模块减少安装与打包成本；类型校验、迁移、状态更新和测试需要自行建立。

不使用 `chrome.storage.sync` 保存完整提示词库。将来若同步少量偏好设置，应重新核对官方配额与写入约束。

暂不引入复杂协作算法，也不把设备时间上的 Last Write Wins 当作已验证的冲突策略。个人多设备编辑仍需保留冲突副本或提供明确选择。

## 后果与重审条件

无网络依赖不保证大数据量下足够快；全量加载与卡片重建需测量。

出现多入口复杂状态、频繁迁移、多种同步适配器或明显维护成本时，再评估类型系统和构建工具。迁移前建立行为基线，保持已有用户数据兼容。
