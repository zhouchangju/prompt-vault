# 快速使用与快捷键

适用版本：0.4.3。

## 鼠标操作

管理页的完整卡片、精简卡片和侧边栏卡片都可以直接点击标题或空白区域使用。无变量时直接复制；有变量时打开填写框，填写后复制。拖选文字不会触发复制。收藏、编辑、删除是独立操作，不会顺带复制。

侧栏左列直接展示全部、收藏、未分类和各文件夹，数字为该分类的提示词总数。切换分类保留当前搜索条件；搜索框的清除按钮可恢复显示当前分类全部结果。分类列和提示词列表分别滚动。

卡片右上星标直接添加/取消收藏，并同步到打开的管理页。取消收藏后，如果正在查看收藏分类，该卡片会从结果中移除。

右上箭头打开或复用完整管理页，然后收起来源侧栏；它不会把整个浏览器切换到系统全屏。新建入口也会在完整管理页打开表单并收起侧栏。

## 排序与布局

侧栏收藏优先；同组按累计使用次数排列。每次打开面板时确定本次顺序，复制只累加次数，不立即移动卡片，也不会在恢复焦点时跳动。下次打开/重新加载面板再应用新的次数；主动收藏/取消收藏会调整优先组。次数相同时保留原排序字段、创建时间及 ID 的稳定顺序。

文件夹拖动排序手柄即可调整顺序，两页同步且重开后保留；聚焦手柄后 Option/Alt+↑/↓ 也可移动。新文件夹默认追加末尾。顶部 + 为新建提示，位于帮助按钮左侧。文字变量默认多行大输入框；数字与选择类型仍保留各自控件。管理页点击当前展示模式按钮即可在精简/完整卡片间切换。

## 快捷键

Mac 的 Command 对应其他平台的 Ctrl，Option 对应 Alt。

| 作用范围 | 按键 | 操作 |
| --- | --- | --- |
| Mac 浏览器 | Option + Shift + P | 打开 / 收起当前窗口的侧边栏 |
| Windows/Linux 浏览器 | Ctrl + Shift + Y | 打开 / 收起当前窗口的侧边栏 |
| 扩展页面 | Command/Ctrl + K | 聚焦并选中搜索内容 |
| 搜索框 | ↓ | 进入当前搜索结果的第一张卡片 |
| 聚焦卡片 | ↑ / ↓ | 在卡片间移动；第一张向上返回搜索 |
| 聚焦卡片 | Enter / 空格 | 使用提示词 |
| 弹窗表单 | Command/Ctrl + Enter | 保存提示词/文件夹，或生成并复制变量内容 |
| 扩展页面非输入区域 | Option/Alt + N | 新建提示词 |
| 弹窗 | Esc | 关闭最上层弹窗 |
| 无弹窗 | Esc | 清空搜索或返回搜索框 |

两页均有快捷键帮助按钮；其中「浏览器中 · 当前实际绑定」读取 Chrome 实际分配结果，不把 manifest 中的建议值当作已绑定。未分配时点击「打开 Chrome 快捷键设置」，自行设置后返回点「刷新检测」。升级扩展不保证覆盖旧绑定。管理页不再单独占用快捷键，使用侧栏右上箭头打开。Chrome 的录入框需先点铅笔进入录制，再实际按下组合键，不能粘贴符号。组合输入期间不执行快捷键；输入框中的正常换行、空格、方向键不被卡片操作劫持。浏览器快捷键可能与系统或其他扩展冲突，在 `chrome://extensions/shortcuts` 查看和调整实际分配。

快捷键状态跟随 Chrome 的原生打开/关闭事件；手动关闭面板后再次按快捷键仍会打开。状态按窗口隔离，并保存在会话存储中以支持后台休眠恢复。一个开关动作尚未结束时，重叠按键合并为一次，避免竞态。

## 兼容性

本版本要求 Chrome 142+，以使用原生关闭通知；Chrome 141+ 提供 [sidePanel.close](https://developer.chrome.com/docs/extensions/reference/api/sidePanel#method-close)，旧版使用窗口关闭回退。当前原生关闭验证覆盖 Chromium 153，旧版回退仅进行了契约测试。管理页复用由 [runtime.openOptionsPage](https://developer.chrome.com/docs/extensions/reference/api/runtime#method-openOptionsPage) 实现；浏览器级绑定使用 [Commands API](https://developer.chrome.com/docs/extensions/reference/api/commands)。

复制成功后的使用记录/列表刷新若失败，会明确提示「已复制，但……更新失败」。剪贴板写入本身失败则保留填写内容供重试。
