# 隐私与权限

适用版本：0.5.0。

提示词、文件夹、使用记录、墓碑、待同步意图及设备/版本元数据保存在扩展 IndexedDB。主题、展示模式和密度保存在 chrome.storage.local；旧设备标识可迁移到 IndexedDB。没有应用层加密或账号登录；可选云同步由页面打开或手动按钮触发。

未配置时没有云请求。配置后仅向用户指定并授权的 Supabase 项目发送三个同步 RPC；没有广告、分析服务、远程字体或脚本。复制将正文或填写后的模板放入系统剪贴板；JSON/CSV 下载可能包含全部存活正文和部分元数据。

| 权限 | 用途 |
| --- | --- |
| storage | 本地设置与旧设备标识兼容读取 |
| sidePanel | 浏览器侧边栏 |
| clipboardWrite | 用户操作后复制提示词 |

无必需 host 权限或 content script。optional_host_permissions 声明 https://*.supabase.co/*，保存连接时按用户手势只申请具体项目 origin，不读取浏览网页内容，也不注入提示词。

删除提示词是软删除，正文仍在数据库中，没有回收站界面。删除分组保留提示词并清除其分组关系。清空数据删除 prompts、folders、syncQueue，保留设备/版本元数据和设置，但删除云端基线与本机冲突恢复快照、重置同步进度；不删除云端数据、已下载备份或系统剪贴板。

JSON 不含墓碑、设置或队列，不是完整数据库镜像。导入预览确认后可覆盖同 ID 记录，先备份。真实导出、浏览器 profile 和私人截图不应进入公共仓库。

为排查快捷键，chrome.storage.session 临时保存最后一次侧栏命令的时间及成功/失败结果，不包含提示词正文；普通鼠标点击不会被记录为快捷键触发。

侧栏开关另外在 chrome.storage.session 中按窗口保存可见状态，只用于恢复后台状态与判断开关，不包含网页内容或提示词。


云连接 URL/key 保存于 chrome.storage.local，不进入数据导出或同步正文；key 仅放在发往配置项目的 apikey 请求头，拒绝重定向，不发送 Cookie 或登录令牌。持有同项目有效 publishable/anon key 的人可通过接口访问整库，因此不将配置公开或与公共网站共用。

云端收到正文、目录、标签、收藏、顺序和设备标识；使用次数、最近使用与主题仅保存在本机。云端保留墓碑和变更历史，软删除不等于擦除。冲突处理前的本地恢复快照保存于 IndexedDB meta，可由用户导出；清空本机也会删除这些快照，云端则不受影响。

页面隐藏或关闭时取消正在进行的同步，不设置 alarms、不轮询、不自动重试或在恢复联网时上传。外发失败不阻塞本地编辑；单次同步仍消耗网络与本地计算资源。
