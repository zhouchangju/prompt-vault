# 隐私与权限

适用版本：0.2.0。

提示词、文件夹、使用记录、墓碑、待同步意图及设备/版本元数据保存在扩展 IndexedDB。主题、展示模式和密度保存在 chrome.storage.local；旧设备标识可迁移到 IndexedDB。没有应用层加密、账号或自动跨设备同步。

运行代码没有云请求、广告、分析服务、远程字体或脚本。复制将正文或填写后的模板放入系统剪贴板；JSON/CSV 下载可能包含全部存活正文和部分元数据。

| 权限 | 用途 |
| --- | --- |
| storage | 本地设置与旧设备标识兼容读取 |
| sidePanel | 浏览器侧边栏 |
| clipboardWrite | 用户操作后复制提示词 |

没有网站 host 权限或 content script，不读取浏览网页内容，也不注入提示词。

删除提示词是软删除，正文仍在数据库中，没有回收站界面。删除分组保留提示词并清除其分组关系。清空数据删除 prompts、folders、syncQueue，保留 meta 和设置以保持设备身份及版本安全；不删除已下载备份或系统剪贴板。

JSON 不含墓碑、设置或队列，不是完整数据库镜像。导入预览确认后可覆盖同 ID 记录，先备份。真实导出、浏览器 profile 和私人截图不应进入公共仓库。

为排查快捷键，chrome.storage.session 临时保存最后一次侧栏命令的时间及成功/失败结果，不包含提示词正文；普通鼠标点击不会被记录为快捷键触发。

侧栏开关另外在 chrome.storage.session 中按窗口保存可见状态，只用于恢复后台状态与判断开关，不包含网页内容或提示词。
