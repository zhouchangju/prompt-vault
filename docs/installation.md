# 安装 Prompt Vault

这是无需构建的 Chrome 扩展。使用 Chrome 142 或更新版本；正式日常使用建议当前稳定版。

1. 本地源码运行 `npm run build`，使用生成的 `dist/prompt-vault/` 目录；若收到 ZIP，则先解压。确认所选目录内有 manifest.json。
2. 在 Chrome 打开 chrome://extensions/，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择上述目录。
4. 点击工具栏扩展图标打开侧边栏，点击侧边栏箭头打开管理页。

管理页顶部可选择「卡片 / 精简」以及主题；设置保存在本地，侧边栏同步使用主题。提示词正文始终参与搜索，精简模式只隐藏预览内容。点击卡片直接复制或填写变量；星标可直接收藏，侧栏左侧可直接切换文件夹。侧栏右上箭头打开管理页后自动收起面板。

更新现有安装时，先导出 JSON 备份，在原安装目录替换文件，然后在扩展管理页点重新加载。不要先卸载扩展；卸载或换目录重新安装可能改变扩展身份并失去原存储访问。

使用构建目录安装后，后续运行 `npm run build` 会更新同一个目录；保留这个安装路径，再到 Chrome 重新加载即可。构建只复制运行必需文件和安装说明，不包含开发依赖、测试或私人数据。ZIP 仍可通过 `npm run package` 单独生成。

JSON 是提示词与文件夹的迁移格式，不包含主题、软删除记录和同步队列。导入前会显示新增/覆盖预览，确认后应用。当前没有云同步，登录浏览器账号不会同步提示词。

CSV 默认用于安全表格交换，对公式前缀进行保护；原始文本 CSV 仅供可信程序处理，无损迁移优先使用 JSON。

Mac 默认 Option+Shift+P 切换侧边栏，其他平台默认 Ctrl+Shift+Y：未打开时打开，已打开时收起。管理页不再单独配置快捷键，通过侧栏右上箭头打开。帮助页显示 Chrome 实际绑定；若未分配，点 Chrome 快捷键设置中的铅笔，再实际按下组合键进行录制。

扩展页面内 Command/Ctrl+K 搜索、方向键选卡片、Enter/空格使用；弹窗内 Command/Ctrl+Enter 保存或生成复制，Esc 关闭。

文件夹可拖动手柄排序。侧栏收藏优先，其余按本次打开时的累计使用次数确定顺序，复制后不会马上重排。文字变量使用大号多行输入框。顶部 + 新建提示，管理页视图用单按钮切换。
